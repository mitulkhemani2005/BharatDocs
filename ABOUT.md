# About BharatDocs

BharatDocs is a PDF field translation app for Windows and the web. It converts configured bill fields into Hindi and keeps the source and translated documents available to the app owner.

The Windows desktop release runs its translation model on the same computer and works offline after installation. The web client and FastAPI service are separate deployments. BharatDocs is intended for configured PDF layouts; translated names, addresses, and amounts should be reviewed before a document is used.

**Repository description:** Offline English-to-Hindi PDF field translator for Windows and web.
