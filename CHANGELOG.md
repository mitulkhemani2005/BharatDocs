# Changelog

## 2.0.0

- Upload a PDF before selecting or creating a reusable configuration.
- Draw, move, rename, and delete individual translation areas on any PDF page; apply the saved layout across all pages.
- Save, copy, edit, and delete configurations locally, including in the offline Windows app.
- Edit each area's maximum Hindi font size directly in the area list, with an option to inherit the configuration default.
- Automatically wrap and reduce Hindi text only when needed, keeping it inside the selected rectangle without moving it to another area or adding pages.
- Improve Devanagari matra spacing with the bundled regular Hindi font.
- Improve PDF layout performance through cached text shaping and faster obstacle clipping.
- Refine the PDF upload card and configuration editor, and remove the built-in bill layout.

The Windows installer includes the translation model and Hindi font. No internet connection, Python, or Node.js is required on the computer using the installed app.
